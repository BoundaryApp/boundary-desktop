# Explainer text UX study

How much explanation the app shows by default, and where the rest goes.

- `index.html`: how other apps handle it, the proposed rules, the `InfoTip` pattern, and a before and after of Settings › Boundary's browser.
- `spec.md`: the inventory, rules, decisions and phases.

Serve the repo root over HTTP to view (the page links the token file by relative path), e.g. `python3 -m http.server` then open `/docs/explainer-text-ux-study/`.
