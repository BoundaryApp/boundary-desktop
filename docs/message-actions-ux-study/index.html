Directions for message actions

Hover verbs and timestamps on chat messages, plus the keyboard layer that goes with them. A covers the request: copy, edit and branch on your prompts, with a timestamp. B applies the same row to assistant replies. C is the keyboard version of both. Mocks follow the centered column from ADR 0020 and the tokens from 0018. Open any file and use the title-bar states. Turn on Notes for callouts.

Held constant

Quiet at restOlder messages show only who spoke. Verbs and time appear on hover or keyboard focus. The latest reply keeps its row visible.
No reflow on hoverThe action row sits in the existing 28px gap between messages. Showing it never moves text.
Rows follow their messageYour prompts sit on the right, so their row aligns right. Replies span the column, so theirs aligns left. The order is always Copy, then Edit or Retry, then Branch, then overflow.
Keyboard parityEvery hover verb is reachable by Tab (:focus-within) and by a named shortcut. Tooltips show the key.
Nothing silently lostEdit and Retry add versions (‹ 2 / 2 ›) and do not overwrite. Branch copies into a new chat. Delete is not offered.
Local-first honestyRetry on another provider says it leaves the machine and what it costs, and follows the project privacy lock.

Recommendation

D · Right bubble. Time goes in the hover row. Pin the latest reply's row. Ship the ChatGPT-compatible keys.

Your prompts hug the right edge of the column, sized to their text, up to 80% of its width. Text stays left-aligned inside the bubble. Replies keep the full column on the left, so the log reads as back-and-forth turns, as in Hermes WebUI and ChatGPT. Alignment says who spoke, so the “You” label goes. Under each prompt, a hover row lines up with the bubble's right edge: time (full date in the tooltip), then Copy, Edit and Branch. Edit makes a version in place and widens to the full column. Branch opens a new chat with the history above and the prompt back in the composer, unsent. Replies get Copy / Retry ▾ / Branch / ⋯ on the left, and code blocks keep their own Copy. A (Under), B (Floating) and C (Head row) stay as foils in the A file.

Open questions

  • Where do timestamps come from? HermesChatMessage has no time field, and history hydrates only role + content. Does the Hermes gateway store per-message times? If it does not, live turns can be stamped in the renderer, but reloaded history has no times.
  • Does edit rewrite the agent's memory? useLocalRuntime can hold client-side versions (BranchPickerPrimitive). The Hermes session is linear, though, and the agent would still see version 1. Edit may need a gateway “rewind to message N” or a fork call.
  • Branch semantics. Proposed: history above the prompt, and the prompt back in the composer unsent. The alternative sends right away. Also decide whether a branch keeps its project, agent and inference override (proposed: yes, all three).
  • Copy format. Proposed: Copy gives markdown, and plain text is in the overflow. Does anyone paste into tools that choke on markdown?
  • ADR 0020 amendment. Right-aligned prompts keep “text stays left-aligned”, but the ADR puts every message on one left edge. Add a line: user turns align right at up to 80% of the column, and agent turns stay full width.
  • Long prompts. At 80% width, a pasted document is cramped. Proposed: collapse past about 12 lines behind Show more, and do not widen the bubble. Not mocked yet.
  • Channels. In a room (0008), is Edit allowed after other agents have replied? Proposed: Branch only, no Edit, once someone else has spoken. Your turns stay on the right and every agent stays on the left, like a group chat.

Implementation notes

  • Primitives exist. @assistant-ui/react ships ActionBarPrimitive (Copy, Edit, Reload). Its autohide="not-last" gives the pinned-latest-reply behaviour in B and BranchPickerPrimitive. UserMessage / AssistantMessage in WorkbenchThread.tsx only need the row added.
  • Shortcuts. Add message commands next to KEY_TO_COMMAND in useAppShortcuts.ts. matchShortcut rejects Shift today, so the ⌘⇧ keys need a second map.
  • Branch. This needs a “new session from history” IPC. The rail then needs a parent link to nest the branch under its source.
