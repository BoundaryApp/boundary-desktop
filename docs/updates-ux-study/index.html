Updates UX study

Updates for Boundary and your tools

Two kinds of update reach a Mac: Boundary itself, which installs on quit, and your tools, which download while they run and install on the next launch. This mock shows where each one surfaces and what it says. The written study, scenario copy and open questions are in README.md next to this file.

Recommendation. Updates surface at the quietest level that works. Failed checks are silent. A new version gets one notice asking before it downloads. A static dot on the Settings icon says an update is ready and clears once the Updates page is opened. Installs happen on the start-up screen of a launch the user started. Dialogs appear only to confirm something the user chose: restarting while work runs, or going back.
