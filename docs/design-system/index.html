Boundary design system

Tokens and primitives shared by setup, the workbench, Services, Resources and Settings. This page loads src/renderer/styles/tokens.css directly, so it always shows what ships. Tailwind names in parentheses come from @theme in src/index.css.

Rules

One solid action per viewThe light solid button is the primary action. Everything else is outline or ghost.
Violet means “you are here” or “we recommend”Selection, the active destination, a recommended option. Not a default button color.
No raw values outside tokens.cssNo hex, no Tailwind palette colors (zinc-*, indigo-*…), no off-scale px sizes in product code.
Same frame everywhereSetup, starting and ready states share the workbench surface, type and rail.
Motion is quiet120 ms for hover and press, 200 ms for panels. Nothing bounces. Reduced motion turns it off.
Every control shows focusKeyboard focus always draws --focus-ring. Never outline: none without a replacement.
