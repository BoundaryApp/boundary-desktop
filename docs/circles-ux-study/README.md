People, models and codes in the prototype are made up. `usage` shows work that depends on metering.

## Products studied

Plex's library access separates what you own from who can reach it, and Tautulli's activity view shows who is using a server now. Tailscale separates inviting someone into a network from sharing one machine with them, the same split as joining a Circle and being shared a model. LM Studio's LM Link lists remote models beside local ones. Open WebUI's permission groups were rejected: they suit administrators of a server, and Circles are a few people who know each other.
