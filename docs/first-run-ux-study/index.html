UX study · first run

Ask for a folder inside setup, and let people skip it

A new user with no project lands in chat with an empty rail. Chats work without a folder, but most of what the assistant does well (reading files, coding) needs one. This study adds a Folders step to the setup flow and moves the rest of the optional setup to a list in the empty chat.

Recommendation. Add Folders as a skippable fourth step between Model and Assistant, shown only on first run. It runs while the stack downloads in the background, so it costs the user no extra time. Other optional setup (calendar, logins, computer access) goes in a Get started list under the empty chat rather than into more setup steps. Setup stays at five steps or fewer. See spec.md for the decisions.
