# Shared folders UX study

| File | Role |
| --- | --- |
| [spec.md](spec.md) | Living spec: flows, decisions, acceptance criteria and phase progress |
| [prototype.html](prototype.html) | Click-through in the Workbench chat frame. The bar above the frame picks a scene, Maya's presence and the theme; `?start=` opens a scene: `folder`, `files`, `share`, `add`, `chat`, `conflict`, `history`, `waiting`, `roles`, `reader`, `project`, `agent`, `remove`, `left`, `empty`. |

People, files and folders in the prototype are made up. The download takes about four seconds there and confirmation about one; real ones depend on the folder's size and on managers being online. Storage, roles and conflict rules are in [ADR 0049](../adr/0049-shared-folders.md). The frame and the Circle place come from the [Circle chats study](../circle-chats-ux-study/README.md), and the project's Folders list from the [coding folders mock](../chat-ux-study/12-coding-folders.html).
