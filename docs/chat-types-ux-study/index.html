Which chat am I in?

Channels moved every Hermes session into Recent, and now nothing says what kind of conversation you're in or where the others are. The root cause is that 0007 made the base agent a DM, like the personalities. Pressing New conversation on that DM turns the old session into an “Untitled leftover” that only shows up in Recent. Users think of Hermes as a place with many separate chats, and of each personality as one ongoing thread. This study gives each type its own shape, name and section, and adds a Mentions view. Open the mock and turn on Notes.

Held constant

One shape per typeSparkle square = Hermes. # = channel. Filled circle = DM. Dashed circle = side chat. The same mark appears in the rail, header, All chats, Mentions, search and @ menus.
Header names the typeEvery header has two lines: the name, then the type in words (“Hermes chat”, “Channel”, “Direct message · one ongoing thread”). The composer placeholder repeats it.
“New” is honest per type⌘N and Hermes + make a new session. Channels + makes a room. DMs + picks an agent and never forks a thread.
Never land on a listThe 0007 rule stays: after ready, open the last-opened conversation or a Hermes chat. Never All chats or Mentions.
Show context cuts honestlyThe DM horizon and context chip appear only once the stack really trims. Messages above the line are dimmed but still readable.
Same rail as todayThe project picker, icon rail, 0014 inspector and 0020 column all stay. Only the left-rail sections and the Recent pane change.

Recommendation

A · Three typed sections: Hermes, Channels, Direct messages. All chats and Mentions sit above them.

Hermes becomes a section with its last five chats inline. Its + is ⌘N from anywhere, and All Hermes chats… opens All chats with the Hermes filter on. Recent is renamed All chats, a typed history of everything with search. Each DM is one ongoing thread. Its header has two tabs: Messages and In channels. In channels is the per-personality @ screen. Each card shows the room, your message, the reply, Open in #room and Continue in DM. A global Mentions row shows the same cards for every agent, with agent chips. Its count is unseen replies, never posts.

Decided · 1 Oct

  1. 0007's rule against nesting is overridden. Hermes is session-based; personalities are not.
  2. The name is “Hermes”, read from one record. Desktop hardcodes it for now, in the built-in agent record only, never as UI literals. The slug stays assistant. When the stack can swap the base agent, the stack fills the record.
  3. Hermes can join channels. New channel pre-checks it. It follows the same member rules as everyone else, it shows up in Mentions, and Continue in a Hermes chat takes the place of Continue in DM.
  4. The DM window is a token budget. The horizon reads “about 6k of 8k tokens”, and the stack reports where the cut falls.
  5. Old per-agent sessions become side chats.
  6. Mentions covers channels only. DMs never appear there.
  7. Activity view is deferred. It may grow out of Mentions later, under its own ADR.
